# Release notes

## Changes

- Updated non-code things.
- The image is buildable again: the download of the server now uses the v3-api of papermc (the v2-api is sunset) and is loaded with a client whose user-agent the host of the files accepts (the default user-agent of urllib is answered with "403 Forbidden")
- The downloaded server is verified against the checksum which the api states, so a truncated or an exchanged download is noticed before it ends up in the image
- The scripts of the codeunit now use the current api of ScriptCollection (the api "TasksForCommonProjectStructure" which they used does not exist anymore, so they were not runnable)
- Updated the versions of the used images
- The Minecraft-EULA can now be accepted using the new environment-variable `accept_minecraft_eula`, so that the server is startable without editing `eula.txt` manually. The verification of the built image uses this variable, which previously failed because the server terminated itself due to the not-accepted EULA
